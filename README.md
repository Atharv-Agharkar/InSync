# 🌐 InSync
> Revolutionizing the social media experience with a sleek UI, feature-rich functionality, and robust authentication—crafted for seamless, real-time interaction.

---

## 🚀 Vision

This platform aspires to **redefine social media** by blending:

- ⚡ User-friendliness  
- 🎨 Aesthetic design  
- 🔐 Strong authentication  
- 📡 Real-time responsiveness via React Query  

Our mission is to deliver a **holistic, modern, and gratifying digital experience** where **performance, design, and usability** converge.

---

## ✨ Features

### 🔐 Authentication System  
- User login, registration, and secure access handling

### 📝 Create & Edit Post  
- Craft new posts  
- Update your content anytime  

### ❤️ Like and Save Functionality  
- Like posts you love  
- Save them to revisit later  

### 🗑️ Delete Post  
- Remove your own content seamlessly

### 🧑‍🎨 Edit Profile  
- Customize your personal information and avatar

### 🔎 Explore & Discover  
- **Explore Page**: View community activity  
- **Profile Page**: View your own timeline  
- **Browse Other Users**: Check out others' profiles  
- **Search Page**: Search for people or content  
- **Saves Page**: Quick access to saved posts  
- **Create Post Page**: Intuitive content publishing  
- **Detailed Post Page**: View individual post details with all interactions

## 🧰 Tech Stack

### 🖥️ Front-end

| Tech          | Description                                            |
|---------------|--------------------------------------------------------|
| **React.js**  | Front-end JavaScript library for UI                   |
| **Tailwind CSS** | Utility-first framework for building responsive designs |
| **Shad-cn**   | UI component library for React (modern & elegant)     |

---

### 🔙 Back-end & State

| Tech            | Purpose                                             |
|------------------|-----------------------------------------------------|
| **Appwrite**     | Authentication, database, and storage backend       |
| **React Query**  | Efficient data fetching and server-state management |
| **TypeScript**   | Strong typing for safer and more maintainable code  |

---

### 🧪 Dev Tools

- ✅ **Visual Studio Code** – Primary code editor  
- 🔍 **React DevTools** – Debug UI components  
- 📁 **Appwrite Console** – Backend management
